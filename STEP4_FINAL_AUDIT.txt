REAL ISSUES FOUND AND FIXED DURING STEP 4
----------------------------------------
A. build_openxechain.sh still emitted obsolete iPhoneTether360-B9C-OXC aliases.
   Removed. Final build outputs are only the 1.0.0 Loader/Core/LicenseID set plus metadata/checksums.

B. Only Core had structural verifier calls and those calls did not provide the verifier's required module kind.
   Fixed. Loader and LicenseID are checked as title PE/XEX; Core is checked as sysdll PE/XEX.

C. XNotifyQueueUI could ultimately execute from Core's raw system worker.
   This contradicted established Xbox 360 homebrew safety practice.
   Fixed. PROC_USER callers may dispatch directly; system callers marshal the UI call through XAM CreateThread ordinal 1084.

D. The legacy verifier and hardware/deployment documentation encoded old B9C assumptions.
   Reconciled to the actual final architecture without weakening the retained Pair/Tether/B9D safety checks.

E. Host validation only syntax-checked top-level src/*.cpp and src/platform/*.cpp.
   Fixed. It now recursively checks all non-BearSSL project translation units and runs dedicated per-target symbol checks.
